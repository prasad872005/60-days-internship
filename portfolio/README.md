# Prasad Gadale - Personal Portfolio

## About the Project

This is my personal portfolio website developed to showcase my skills, education, projects, learning experience, and contact information.

The portfolio represents my journey as a final-year Computer Science Engineering student interested in Full Stack Web Development.

- About Me section

- Education details
- Project showcase
- Experience and learning section
- Contact information

## Projects

### 1. RideNow - Bike Rental Website

A bike rental website that allows users to browse available bikes, view bike details, and make rental bookings.

**Technologies:** HTML, CSS, JavaScript, React.js, Node.js, Express.js, MySQL

### 2. ShopEZ - E-Commerce Application

A full-stack MERN e-commerce application where users can browse products, manage their cart, place orders, and submit reviews.

**Technologies:** MongoDB, Express.js, React.js, Node.js

### 3. Page Pulse - Website Audit Tool

A website auditing tool that analyzes a webpage and provides information such as HTTP status, response time, page title, meta description, H1 count, missing image alt text, and approximate word count.

**Technologies:** React.js, Node.js, Express.js

\## Project



\### AuthUI - Login \& Registration System



This project is a frontend authentication interface created as part of Task 2 of the 60 Days Internship.



It includes responsive Login and Registration pages with JavaScript-based validation and interactive features.



\## Features



\- Responsive Bootstrap 5 design

\- Mobile-friendly UI

\- Responsive Navbar

\- Login page

\- Registration page

\- Name validation

\- Email validation

\- Password validation

\- Confirm password matching

\- Show/Hide password

\- Terms and Conditions validation

\- Dummy AJAX email availability check

\- Login validation

\- Registration to Login flow

\- Hover effects

\- Bootstrap Icons

\- Custom CSS styling
